# Darlin Phones & Accessories

Next.js App Router showcase using React components and CSS. Product images live in `public/assets`.

```sh
npm install
npm run dev
```

`npm run build` generates the production static export in `out/`. Sites publishes that directory using `.openai/hosting.json`.

The shortlist is stored in the visitor's browser. Product availability, prices, and business contact details still require confirmation.
